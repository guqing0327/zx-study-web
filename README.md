# 正贤学习平台 · 网页试用版

这是基于 [正贤学习平台 v0.1.2](https://github.com/132465798a/zx-study/releases/tag/v0.1.2) 的浏览器练习版。支持小学一至六年级语文、数学、英语，共 74,115 道原版题目。

从科目、年级和题型中抽取 5、10 或 20 道题，可以逐题作答、查看答案与原题解析、重做错题，或把练习卷连同可选答案页打印为 PDF。错题记录只保存在当前浏览器。清除网站数据会清除记录。原桌面版的语音跟读、家庭账号、游戏与考试管理未移植。

## GitHub Pages

发布来源选择 main 分支的 /docs 目录。站点为静态文件，使用相对路径，可以从项目子目录访问。网页运行时无需后端服务。

## 题库与许可

题库按学科、年级拆为 18 个文件，每次只加载选中的分组。可使用 Python 3 从原版 v0.1.2 数据库重新生成：

```sh
python3 scripts/export_bank.py /path/to/zx-study/build/bank.db
```
